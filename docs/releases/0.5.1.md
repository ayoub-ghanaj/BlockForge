# Minecraft Builder 0.5.1

Includes all 0.5.0 features: visible-face matching, imported textured previews,
bulk editing and edited-perimeter protection checks.

This update makes block selection accessible without keyboard shortcuts:

1. Enable block editing in the Minecraft tab or Perimeter Step 5.
2. Click **Select Area (2 Clicks)**.
3. Click two opposite corner blocks in the viewport.
4. Choose a brush, then **Repaint blocks**, **Fill box**, or **Delete blocks**.

**Pick Block** also starts the viewport tool directly. The panel displays whether
it is active or stopped, and the viewport header explains the next click. Repeated
starts reuse one modal tool. Blender Object Mode is required with a clear message
if the user is in another mode. V/B/C remain optional while the tool is active.

Save your .blend, install `minecraft_builder-0.5.1.zip`, then restart Blender.
See `docs/FEATURES_050.md` and `docs/LIVE_EDITING.md` for instructions.

Windows Blender 5.2.2 mouse-event tests passed for both workflows, including
selection started from a stopped tool, two clicks without shortcuts, repeated
button activation, sidebar editing and existing drag/Undo behavior. Conversion
and export algorithms are unchanged from the locally game-tested 0.5.0 feature set.
The private GitHub release includes CI-tested ZIP and example files.
