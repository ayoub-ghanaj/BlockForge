# Minecraft Builder 0.3.1

## Fix

Fixes updates from a disabled older add-on retaining stale Python modules and RNA
settings. This caused missing `palette_settings` and `edit_enabled` errors in the
live editor. Dependencies now refresh together before Blender classes register.

The tests cover direct upgrades and recovery from an already-mixed 0.3.0 session,
preserving version selection, generated previews and saved manual edits.

## Included

- Model conversion with cubes, stairs/slabs and hollow/solid controls.
- Separate Perimeter Designer for image floors/walls and 3D decorations.
- Searchable block rules, exclusive allow-lists, survival preset and 1-meter preview.
- Live block add/delete/repaint/move and saved Undo/Redo in both workflows.
- Dry ground covers, colored glass and version-aware lighting choices.
- WorldEdit `.schem`, Litematica `.litematic` and Axiom `.bp` exports.

## Install

Save your scene. Install `minecraft_builder-0.3.1.zip` using Blender Preferences →
Add-ons → Install from Disk, then restart Blender. The examples archive includes
Blender scenes, source images, exports, previews and recorded verification reports.

Java 26.1.2 has actual local mod-reader/world tests. The 51 Java presets have
registry validation; pre-1.13 formats and Bedrock are not implemented.
