# Minecraft Builder 0.5.3

Fix conversion failing with "bake the Base Color node chain" for UV textures
connected through a Hue/Saturation/Value node. Color matching now preserves
the node's hue, saturation, value and factor adjustments.

- Support constant Point Mapping transforms and reroutes in UV texture chains.
- Evaluate color adjustments in scene-linear space before block matching.
- Keep clear bake instructions for unsupported nodes or linked node controls.
- Check adjusted texture colors against Cycles emission bakes in CI, alongside
  generation, installation and upgrade tests.

Install `minecraft_builder-0.5.3.zip` using Blender's **Install from Disk** menu.
Save your work and restart Blender after upgrading an enabled older add-on.
Select your source model and regenerate the block preview.
