# Minecraft Builder 0.4.0

## Palette audit

- Audited all 47,572 registry entries across all 51 supported stable Java releases.
- Added 31–51 materials per version without removing existing palette entries.
- Minecraft 26.1.2 grows from 481 to 529 materials; 26.3 grows from 573 to 624.
- Mushroom blocks, mushroom stems and chiseled bookshelves are now supported.
- Optional glass, ice, leaves, grass and other translucent materials; solid
  materials remain the default. Leaves use persistent states.
- Each release uses its own model/texture assets, UVs, multipart definitions,
  animated texture timings, alpha layers and tint reference.
- Version-specific colors for ground covers; corrected experimental copper
  trapdoor availability and tinted-glass light obstruction.
- Exhaustive inclusion/exclusion records and asset provenance in the repository.

## Use

Install `minecraft_builder-0.4.0.zip`, save and restart Blender. In existing scenes,
click **Reload Block Preset**, then regenerate. This keeps Include/Exclude rules
and refreshes colors. Check **Allow glass / biome colors** to use optional rows.

The examples archive includes the 529-material gallery in WorldEdit, Litematica
and Axiom formats, with a coordinate/material CSV and game verification report.

Minecraft 26.1.2: 2,853 exact game shapes checked, 19,872 cells checked through
each of the three real readers and again after placement. Historical presets
have registry/property/asset validation, not a claim of 51 game runtime tests.

Plants, doors, fences, technical blocks and other unsupported shapes remain
explicitly excluded. Pre-1.13 and Bedrock adapters are still not implemented.
