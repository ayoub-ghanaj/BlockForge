# Minecraft Builder 0.3.2

- Keep picked block coordinates selected while moving the mouse to the sidebar.
- Let sidebar buttons, fields and shortcuts work during viewport block editing.
- Preserve viewport add/delete/drag and block Undo/Redo in both workflows.
- Includes the 0.3.1 fix for cached modules causing missing `palette_settings`
  and `edit_enabled` after an update.

Install `minecraft_builder-0.3.2.zip` from Blender Preferences → Add-ons →
Install from Disk. Save your scene and restart Blender after upgrading.

The examples ZIP contains versioned Minecraft 26.1.2 exports, Blender scenes,
images, previews and verification reports. Source, tests and guides are in this
private repository. Releases require both GitHub Actions test jobs to pass.

Local Windows Blender 5.2.2 mouse simulation verified picking, sidebar checkbox
and Delete clicks without exiting the tool, then viewport Undo in both Model and
Perimeter. CI checks core formats, Blender generation/editing, ZIP installation
and upgrades; it does not perform desktop mouse or Minecraft tests.

For Axiom files saved under nested folders, open the relevant folder or enable
**Search inside Folders**, clear filters and refresh. The browser displays the
export's **Build name** (for example “Minecraft build”), which can differ from the
filename. Compressed small builds can legitimately occupy only a few kilobytes.
