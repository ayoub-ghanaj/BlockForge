# Minecraft Builder 0.5.0

- Match exposed model faces and inward floor/wall colors, selecting legal block
  orientations from all 51 bundled Java presets.
- Optional textured previews from an explicitly imported resource ZIP/JAR, with
  packed atlases, missing-texture fallback and support for live-edited sections.
- Box selection, radius brushes, bulk fill/repaint/delete/replace, copy/paste and
  mirrored blocks in both Model and Perimeter editors. One operation is one Undo.
- Recheck edited perimeter protection, highlight issues, and catch unsupported
  covers on honey/leaves. Check lighting alone or require dry covers.

Install `minecraft_builder-0.5.0.zip` through Blender **Install from Disk**, then
restart Blender. Use **Reload Block Preset** for new per-face/orientation metadata.
Existing scenes keep average matching until **Match visible block faces** is enabled.

See `docs/FEATURES_050.md` for instructions and preview/checking limits. The
examples ZIP includes generic fixtures, packed previews, all three export formats
and test reports under `latest/features-0.5.0/`. Runtime features have no special
cases for the cat, skull, any model name, file path or chosen dimensions.

Verified locally with 44 offline tests, Blender 5.2.2 integration/viewport events,
and Minecraft Java 26.1.2 using the actual WorldEdit, Litematica and Axiom readers.
The game checked 3,076 shape variants, 1,348 cells per format and in the world,
120 edited cover positions, 28 edited light positions, and 143 cover/support
combinations. A 520,000-block perimeter also passed editing and bulk Undo checks.
Historical presets have registry validation, not individual launched-game tests.
