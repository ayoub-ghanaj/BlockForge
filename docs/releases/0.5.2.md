# Minecraft Builder 0.5.2

This maintenance release improves readability and prepares the repository for
public contributions. Model conversion, perimeter controls, saved edits, and all
three export formats retain their existing behavior.

- Consistent Python formatting, imports, and descriptive settings names.
- Smaller helpers for model panels, snapshot installation, and viewport editing.
- Typed palette and selection boundaries, with unused code removed.
- Public pull-request checks and releases gated on Python and Blender tests.
- GPL-3.0-or-later license at the repository root and in the extension package.
- Development documentation and a source tree that excludes local recovery
  archives, imported model scenes, and machine-specific reports.

Install `minecraft_builder-0.5.2.zip` from Blender's **Install from Disk** menu.
Restart Blender after upgrading an enabled older add-on.
